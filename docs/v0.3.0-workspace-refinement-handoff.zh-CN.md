## LG-305 实现细节

- 标题由 `universes.current.name` 计算得出（`computed`），世界切换、重命名或刷新后自动反映；世界名为空时退化为 `Graph`。
- 主区用 `flex flex-col` + 固定 48px 的 `header`（`shrink-0`）+ `min-h-0 flex-1` 的画布容器：画布始终填满标题下方的剩余高度，不挤压工具栏、缩放控件和小地图。
- 新增测试锚点：`workspace-main`、`workspace-context-header`、`workspace-title`。
- 未改动 Sidebar / Inspector / AppShell / GraphCanvas 的结构与已验收尺寸：展开 264px、收起 rail 56px、Inspector 336px、899px 窄屏断点。
- 没有新增第二个“新建节点”入口；画布工具栏仍是唯一入口。
